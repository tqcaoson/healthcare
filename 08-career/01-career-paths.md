## Career Paths trong Health IT

---

### 1. Career Map — Từ Dev đến Senior Health IT

```
Entry Level                  Mid Level                   Senior Level
─────────────────            ─────────────────           ─────────────────
Junior Dev (generalist)  →   EHR Developer           →   Lead Developer
                         →   Integration Engineer     →   Solutions Architect
                         →   Data Engineer            →   Data Architect
                         →   Security Analyst         →   CISO
                         →   Implementation Analyst   →   CMIO (nếu clinical)
                         →   Health Informaticist     →   VP/Director
```

---

### 2. Role Chi Tiết

#### 🔌 Integration Engineer

**Làm gì:** Build và maintain HL7/FHIR interfaces giữa hệ thống.

| Khía cạnh | Chi tiết |
|-----------|---------|
| Daily work | Mirth Connect channel builds; HL7 message debugging; FHIR API integration |
| Tech stack | HL7 v2, FHIR R4, Mirth Connect, Java/JavaScript, SQL |
| Domain cần biết | ADT workflows, lab/radiology/pharmacy processes |
| Salary (US) | $80K–$140K |
| High demand | ✅ Mọi bệnh viện cần; không bao giờ thất nghiệp |

#### 📊 Health Data Engineer

**Làm gì:** Build data pipelines từ clinical systems đến analytics/ML.

| Khía cạnh | Chi tiết |
|-----------|---------|
| Daily work | ETL pipelines, OMOP CDM, data quality, FHIR bulk export |
| Tech stack | Python/Spark, dbt, Airflow, SQL, FHIR, OMOP |
| Domain cần biết | Clinical terminologies (LOINC, SNOMED, ICD), data governance |
| Salary (US) | $100K–$160K |
| Growth | ✅✅ Analytics và ML healthcare đang boom |

#### 🏥 EHR Developer / Application Developer

**Làm gì:** Build EHR apps, customize EHR, build SMART on FHIR apps.

| Khía cạnh | Chi tiết |
|-----------|---------|
| Daily work | SMART on FHIR apps, CDS Hooks services, EHR customization |
| Tech stack | FHIR R4, SMART, JavaScript/React, Java/C#, SQL |
| Domain cần biết | Clinical workflows, CPOE, medication management |
| Salary (US) | $90K–$150K |

#### 🔒 Healthcare Security Engineer

**Làm gì:** Bảo vệ ePHI, HIPAA compliance, incident response.

| Khía cạnh | Chi tiết |
|-----------|---------|
| Daily work | Security assessments, HIPAA audits, SIEM monitoring, pentest |
| Tech stack | SIEM (Splunk), IAM, encryption, network security |
| Domain cần biết | HIPAA Security Rule, NIST CSF, medical device security |
| Salary (US) | $110K–$180K |
| Certifications | CISSP, HCISPP (healthcare specific) |

#### 🤖 Clinical ML Engineer / AI Engineer

**Làm gì:** Build và deploy ML models trong clinical setting.

| Khía cạnh | Chi tiết |
|-----------|---------|
| Daily work | Feature engineering từ EHR data, model training, clinical validation |
| Tech stack | Python, PyTorch/TensorFlow, FHIR, OMOP, MLflow |
| Domain cần biết | Clinical workflows, FDA SaMD, model bias, explainability |
| Salary (US) | $130K–$200K |
| Barrier | Cao nhất — cần clinical + ML + regulatory knowledge |

### 3. Kỹ năng cần theo level

| Level | Technical | Domain | Soft Skills |
|-------|-----------|--------|------------|
| **Entry** | 1 ngôn ngữ, SQL, Git | HIPAA basics, EHR overview | Communication với non-tech |
| **Mid** | FHIR hoặc HL7, cloud basics | Clinical workflows, terminologies | Clinical stakeholder management |
| **Senior** | Full stack health IT, security | End-to-end domain expertise | Architecture decisions, mentoring |
